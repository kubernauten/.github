## que hacemos

-   **Kubernetes administrado**: Trabajamos con ofertas SaaS como**AKS**(Azur) y**EX**(AWS).
-   **Kubernetes autohospedado**: Ejecutamos nuestros propios clusters con**como un palo**.
-   **Proyectos de ejemplo y aprendizaje.**: Construimos proyectos juntos para probar conceptos en la práctica.
-   **Certificaciones**: Nos preparamos juntos para las certificaciones de Kubernetes.
